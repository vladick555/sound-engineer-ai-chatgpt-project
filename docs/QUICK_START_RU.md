# Quick Start

1. Download this repository as ZIP.
2. Create a new Project in ChatGPT.
3. Open `chatgpt_sources/00_PROJECT_INSTRUCTIONS_PASTE_IN_CHATGPT.md`.
4. Copy the text into Project Instructions.
5. Upload all other files from `chatgpt_sources` into Sources.
6. Edit `02_USER_PLUGIN_PROFILE_TEMPLATE.md` with your DAW, plugins and sound goals.
7. Start with:

"Act as Sound Engineer AI. Use my plugin profile and project sources. Help me analyze my mix, plugin screenshots and vocal chains."
