# Позиционирование продукта

## Что это

Sound Engineer AI — это готовый набор файлов для ChatGPT Project, который помогает превратить ChatGPT в ассистента по сведению, мастерингу, DAW и плагинам.

## Что это не

Это не отдельное приложение.
Это не встроенная AI-модель.
Это не замена звукорежиссёру.
Это не база украденных мануалов.

## Правильное описание

```text
Ready-to-use ChatGPT Project Pack for plugin screenshot analysis, DAW help, vocal chains, mixing and mastering feedback.
```

## Короткое описание на русском

```text
Готовый пакет инструкций и источников для ChatGPT Project, который помогает артистам, продюсерам и звукорежиссёрам анализировать плагины, цепочки обработки, микс и мастер.
```

## Основной крючок

Обычный ChatGPT отвечает слишком общо. Sound Engineer AI заставляет его отвечать как практический звукорежиссёр: с учётом DAW, плагинов, скринов, аудио и цели пользователя.

## Для кого

- артистов
- продюсеров
- битмейкеров
- домашних студий
- начинающих инженеров
- людей, которые хотят понимать звук

## Главная фраза

```text
Upload the files into a ChatGPT Project and start analyzing your plugins, vocal chains, mixes and masters.
```
