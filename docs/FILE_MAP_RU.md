## chatgpt_sources/

Это главная папка. Именно эти файлы нужны пользователю для ChatGPT Project.

### 00_PROJECT_INSTRUCTIONS_PASTE_IN_CHATGPT.md

Главные инструкции. Их надо вставить в Project Instructions.

### 01_SOUND_ENGINEER_ROLE.md

Определяет роль ассистента.

### 02_USER_PLUGIN_PROFILE_TEMPLATE.md

Шаблон профиля пользователя: DAW, плагины, микрофон, цели звука.

### 03_OFFICIAL_MANUAL_SOURCES.md

Список официальных источников по DAW и плагинам.

### 04_SCREENSHOT_ANALYSIS_RULES.md

Правила анализа скринов плагинов.

### 05_AUDIO_FILE_ANALYSIS_RULES.md

Правила анализа WAV/MP3/AIFF.

### 06_VOCAL_CHAIN_SYSTEM.md

Логика построения вокальной цепочки.

### 07_MASTERING_CHAIN_SYSTEM.md

Логика мастеринга.

### 08_DAW_WORKFLOW_RULES.md

Правила помощи по Logic, Ableton, FL Studio.

### 09_PLUGIN_STARTING_SETTINGS.md

Стартовые настройки для EQ, компрессоров, de-esser, reverb, delay, limiter.

### 10_RESPONSE_TEMPLATES.md

Шаблоны ответов.

### 11_TROUBLESHOOTING_DECISION_TREE.md

Дерево диагностики проблем: муть, резкость, тихий вокал, сломанный мастер.

### 12_COPYRIGHT_AND_SAFETY_RULES.md

Правила по авторским правам и приватности.

### 13_USER_ONBOARDING_FIRST_MESSAGE.md

Первое сообщение, которое пользователь отправляет внутри проекта.
