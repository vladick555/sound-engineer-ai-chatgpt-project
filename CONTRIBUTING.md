# Contributing

Спасибо, что хочешь улучшить Sound Engineer AI.

## Что можно добавлять

- новые правила анализа плагинов
- новые шаблоны ответов
- новые примеры запросов
- новые официальные ссылки на документацию
- улучшения структуры ChatGPT Project Pack

## Что нельзя добавлять

- копии чужих PDF-мануалов
- платные пресеты
- чужие семплы
- чужие WAV/MP3 без прав
- API-ключи
- приватные пользовательские данные

## Стиль правок

Пиши практично и понятно. Не превращай проект в академический учебник. Главная ценность проекта — конкретные действия: что крутить, почему, какие настройки попробовать и чего не делать.
