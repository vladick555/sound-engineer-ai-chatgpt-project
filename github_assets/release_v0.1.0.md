# v0.1.0 — Initial ChatGPT Project Pack

First public version of Sound Engineer AI ChatGPT Project Pack.

## Includes

- Project instructions
- User plugin profile template
- Official manual source index
- Screenshot analysis rules
- Audio analysis rules
- Vocal chain system
- Mastering chain system
- DAW workflow rules
- Plugin starting settings
- Response templates
- Troubleshooting decision tree
- Copyright and privacy rules
- GitHub upload guide

## How to use

Create a ChatGPT Project, paste the instructions from `00_PROJECT_INSTRUCTIONS_PASTE_IN_CHATGPT.md`, upload the remaining files from `chatgpt_sources` into Sources, and start chatting.
