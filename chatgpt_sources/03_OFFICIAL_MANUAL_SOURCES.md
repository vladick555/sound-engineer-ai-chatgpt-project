## How to use sources

When the user asks about exact DAW/plugin behavior:

1. Prefer official documentation if available.
2. If browsing is available, check the official source.
3. If browsing is unavailable, rely on the project rules and ask the user to paste the relevant manual section if exact details matter.
4. Do not invent official claims.
