# Plugin Starting Settings

These are safe starting points, not fixed rules. Always adjust by ear.

## FabFilter Pro-Q style EQ

### Lead vocal cleanup

- high-pass: 70–120 Hz
- mud dynamic cut: 180–350 Hz, 1–4 dB
- boxiness cut: 300–600 Hz, 1–3 dB
- harshness dynamic control: 3–6 kHz, 1–4 dB
- air shelf: 10–16 kHz, 1–3 dB if needed

### Beat vs vocal masking

If vocal is hidden by beat:

- dynamic dip on beat around 1.5–4 kHz triggered by vocal if possible
- small static cut on beat where vocal needs space

## 1176 / CLA-76 style compression

### Lead vocal

- ratio: 4:1 or 8:1
- attack: medium-fast
- release: fast
- gain reduction: 2–5 dB

### Aggressive adlibs

- ratio: 8:1 or 12:1
- faster release
- more reduction if it fits the effect

## LA-2A / leveling style compression

### Lead vocal

- reduction: 1–4 dB
- use after fast compressor or before, depending on tone
- good for smoothing, not for controlling every sharp peak alone

## De-esser

### Male trap vocal

- focus: 5–8 kHz
- reduction: 2–5 dB

### Bright vocal

- focus: 6–10 kHz
- reduction: 1–4 dB

## Saturation

### Vocal density

- drive: low to medium
- mix: 5–25%
- avoid harsh 3–6 kHz buildup

### 808 translation

- add harmonics above sub area
- keep sub mono
- do not overdistort if kick disappears

## Reverb

### Lead vocal plate/hall

- pre-delay: 20–60 ms
- decay: 1.2–2.8 s
- low cut: 150–300 Hz
- high cut: 6–10 kHz
- use send, not heavy insert

## Delay

### Trap/R&B vocal delay

- timing: 1/4, 1/8, 1/8 dotted
- feedback: low to medium
- low cut: 150–300 Hz
- high cut: 3–8 kHz
- automate throws

## Stereo width

### Lead vocal

- keep main body centered
- avoid widening lows
- use width mostly on doubles/adlibs/sends

### Adlibs

- pan wider
- more modulation/reverb/delay
- reduce low-mid mud

## Clipper

### Before limiter

- clipping: 1–3 dB first
- oversampling: on if available
- listen for snare/vocal/808 distortion

## Limiter

### Streaming master

- true peak ceiling: around -1 dBTP
- avoid constant heavy gain reduction
- compare level-matched before/after
