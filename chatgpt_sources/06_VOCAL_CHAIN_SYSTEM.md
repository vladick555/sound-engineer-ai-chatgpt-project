# Vocal Chain System

This file defines practical vocal chain logic for modern melodic trap, urban trap, R&B trap and night drive rap.

## Default lead vocal chain

1. Noise cleanup / manual editing
2. Tuning
3. Cleanup EQ
4. First compression / leveling
5. De-esser
6. Tone EQ
7. Saturation
8. Second compression / control
9. Sends: reverb, delay, width
10. Vocal bus processing
11. Automation

## Why this order

### 1. Cleanup before processing

Remove noise, clicks, bad breaths and empty spaces before heavy processing. Do not rely on plugins to fix bad editing.

### 2. Tuning early

For modern trap, tuning usually works better before heavy compression and saturation.

### 3. Cleanup EQ before compression

If muddy frequencies hit the compressor, the compressor reacts to mud. Remove obvious low-end rumble and boxiness first.

### 4. Compression in stages

One compressor doing 10 dB of reduction often sounds worse than two compressors doing 2–4 dB each.

## Starting settings

### Tuning

For strong modern trap tuning:

- key/scale: must match song key
- retune speed: fast
- humanize: low to medium
- formant: avoid extreme changes unless it is an effect

If tuning sounds wrong, check key before changing every knob.

### Cleanup EQ

Lead vocal starting points:

- high-pass: 70–120 Hz depending on voice
- mud check: 180–350 Hz
- boxiness check: 300–600 Hz
- harshness check: 3–6 kHz
- sibilance check: 5–10 kHz
- air: 10–16 kHz

Do not remove too much 150–250 Hz or vocal becomes thin.

### Compression

Fast compressor / 1176-style:

- ratio: 4:1 or 8:1
- attack: medium-fast, not always fastest
- release: fast/medium-fast
- gain reduction: 2–5 dB for main vocal

Slower leveling compressor:

- ratio: 2:1 to 4:1
- attack: medium
- release: auto or medium
- gain reduction: 1–4 dB

### De-esser

Starting points:

- male vocal: often 5–8 kHz
- bright vocal: 6–10 kHz
- reduction: 2–5 dB on harsh esses

If de-esser lisps the vocal, it is too aggressive.

### Saturation

Use saturation for density, not just distortion.

Starting points:

- mix amount: 5–25%
- drive: low to medium
- focus: mids/high-mids if vocal needs presence
- avoid harsh 3–6 kHz buildup

### Reverb send

Starting points:

- pre-delay: 20–60 ms
- decay: 1.2–2.8 s depending on tempo
- low cut: 150–300 Hz
- high cut: 6–10 kHz
- send level: low enough that vocal stays upfront

### Delay send

Starting points:

- 1/4 for spacious lines
- 1/8 or 1/8 dotted for bounce
- low cut: 150–300 Hz
- high cut: 3–8 kHz
- automate throws at line endings

## Adlibs / backs

Adlibs can be more processed than lead:

- wider stereo
- more reverb/delay
- more formant effects
- more filtering
- lower volume than lead
- less low-mid body

## Common mistakes

1. Too much reverb on lead.
2. Tuning in wrong key.
3. Cutting all body from vocal.
4. Boosting air before fixing harshness.
5. Compressing too hard before EQ.
6. Making adlibs louder than lead.
7. Using stereo widening on lead low frequencies.
