# Mastering Chain System

This file defines practical mastering logic for modern trap, melodic rap, R&B and night-drive tracks.

## Core principle

Do not fix the mix with mastering if the mix itself is broken.

If vocal is buried, 808 is unstable, or harshness is painful, fix the mix first.

## Default mastering chain

1. Metering before processing
2. Corrective EQ
3. Gentle glue compression if needed
4. Saturation / color if needed
5. Dynamic EQ / multiband control
6. Stereo control
7. Clipper
8. Limiter / maximizer
9. Final metering

## Corrective EQ

Use small moves:

- low-end rumble: below 20–30 Hz
- mud: 180–350 Hz
- harshness: 3–6 kHz
- air: 10–16 kHz

On master, avoid huge EQ moves unless it is a deliberate creative effect. If you need more than 3 dB, the mix probably needs work.

## Compression

Master bus compression should be subtle.

Starting points:

- ratio: 1.5:1 to 2:1
- attack: 10–30 ms
- release: auto or 100–300 ms
- gain reduction: 0.5–2 dB

If compressor kills kick/808 impact, back off.

## Dynamic EQ / multiband

Use for:

- 808 boom control
- harsh vocal peaks
- aggressive hi-hats
- low-mid buildup

Do not overdo multiband compression. It can make the track flat and lifeless.

## Clipper before limiter

Clipper can help loudness by shaving short peaks before the limiter.

Starting points:

- oversampling: on if available
- clipping: 1–3 dB first
- listen to drums, vocal consonants and 808

If snare loses punch or vocal cracks, clipping is too much.

## Limiter / maximizer

Starting points:

- ceiling: around -1.0 dBTP for streaming-safe exports
- loudness target: depends on style, usually around -10 to -7 LUFS for modern loud trap references, but do not chase LUFS blindly
- gain reduction: avoid constant heavy 5–8 dB reduction unless it is intentional and still sounds clean

## Loudness rule

A clean -9 LUFS master is better than a destroyed -6 LUFS master.

## Check before export

1. Does vocal stay clear?
2. Does kick still hit?
3. Does 808 distort unpleasantly?
4. Does high-end hurt at normal volume?
5. Does track collapse in mono?
6. Does limiter pump on chorus?
7. Does the master sound better than the mix, not just louder?

## Common mistakes

1. Adding Ozone presets without understanding modules.
2. Using limiter to solve mix balance.
3. Making 808 too wide.
4. Boosting high shelf too much.
5. Cutting lows until the track loses weight.
6. Exporting without level-matched comparison.
