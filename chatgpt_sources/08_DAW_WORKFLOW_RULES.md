# DAW Workflow Rules

Use this file when helping with Logic Pro, Ableton Live and FL Studio workflows.

## General DAW principles

- Explain steps using the user's DAW when known.
- If DAW is unknown, ask or give paths for Logic/Ableton/FL separately.
- Prefer simple routing first.
- Explain sends, buses and automation in practical terms.

## Logic Pro

Common workflows:

### Sends

Use sends for reverb, delay, parallel compression and special effects.

Practical logic:

- Lead vocal insert chain stays clean and controlled.
- Reverb/delay go on aux channels.
- Automate send level for throws and transitions.

### Automation

Use automation for:

- vocal volume rides
- delay throws
- reverb throws
- filter sweeps
- adlib moments
- master effects only if deliberate

### Stock alternatives

If user does not have third-party plugins:

- Channel EQ instead of Pro-Q
- Logic Compressor instead of CLA-76/Pro-C
- DeEsser 2 instead of Pro-DS/Sibilance
- ChromaVerb instead of Valhalla
- Tape Delay instead of EchoBoy
- Adaptive Limiter instead of Pro-L/Ozone Maximizer

## Ableton Live

Common workflows:

### Racks

Use Audio Effect Rack for:

- parallel vocal chains
- macro controls
- wet/dry blends
- live performance processing

### Sends / Returns

Use Return tracks for:

- reverb
- delay
- parallel saturation
- parallel compression

### Stock alternatives

- EQ Eight instead of Pro-Q
- Compressor / Glue Compressor instead of Pro-C/CLA-76
- Saturator instead of Saturn/Decapitator
- Echo instead of EchoBoy
- Hybrid Reverb instead of Valhalla
- Utility for gain/stereo/mono checks

## FL Studio

Common workflows:

### Mixer routing

Route vocals to:

- lead vocal channel
- adlibs channel
- vocal bus
- send channels for reverb/delay

### Automation clips

Use automation clips for:

- send levels
- filter sweeps
- delay feedback
- reverb throws
- vocal effects

### Stock alternatives

- Parametric EQ 2 instead of Pro-Q
- Fruity Compressor / Limiter compression mode instead of Pro-C
- Maximus for multiband/master control
- Reeverb 2 instead of Valhalla
- Delay 3 instead of EchoBoy
