# Troubleshooting Decision Tree

Use this when the user says something is wrong but does not know why.

## Problem: vocal is muddy

Check in this order:

1. Is there too much 180–350 Hz on vocal?
2. Is reverb return low-cut missing?
3. Is the beat masking vocal low-mids?
4. Is compression reacting to low-mids?
5. Is stereo widening smearing the vocal?

Actions:

- dynamic cut 180–350 Hz
- low-cut reverb/delay returns
- sidechain dynamic EQ on beat
- reduce saturation low-mids
- check vocal without effects

## Problem: vocal is harsh

Check:

1. 3–6 kHz boosted too much?
2. Saturation before de-essing?
3. De-esser too late or too weak?
4. Master limiter exaggerating harshness?

Actions:

- dynamic EQ 3–6 kHz
- de-ess 5–10 kHz
- reduce high shelf
- check saturation drive

## Problem: vocal is behind beat

Check:

1. Lead vocal volume too low?
2. Too much reverb?
3. Beat masking 1.5–4 kHz?
4. Vocal too dark?
5. Compression killing consonants?

Actions:

- volume ride vocal
- reduce reverb wet/send
- dynamic dip beat 1.5–4 kHz
- add controlled presence
- check attack time on compressor

## Problem: 808 disappears on phone

Check:

1. 808 has no upper harmonics?
2. Sub too low only below 50 Hz?
3. Kick/808 phase conflict?
4. Too much limiting?

Actions:

- add saturation harmonics
- layer or shape 808 mids
- tune 808 to song key
- check mono
- sidechain kick/808 if needed

## Problem: master loud but distorted

Check:

1. Limiter doing too much reduction?
2. Clipper too aggressive?
3. 808 eating headroom?
4. Harsh high-end hitting limiter?
5. Mix too unbalanced before master?

Actions:

- reduce limiter input
- control sub before limiter
- clip only 1–3 dB first
- dynamic EQ harsh peaks
- fix mix balance

## Problem: mix sounds small

Check:

1. Too much low-end cut?
2. Vocal too dry or too narrow?
3. No contrast between lead/adlibs?
4. Over-compression?
5. No automation?

Actions:

- restore body
- widen adlibs/sends, not low lead body
- add delay throws
- automate sections
- reduce bus compression
